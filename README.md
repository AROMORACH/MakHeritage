# MakHeritage Project: README

## Overview
MakHeritage is a digital historical and spatial archive designed to preserve and showcase the rich heritage of Makerere University. The platform serves as an interactive repository where users can explore the foundational architecture, traditional residential sub-cultures, academic colleges, and essential infrastructural nodes of "The Hill".

## Project Requirements
* **Historical Accuracy**: All data nodes must strictly align with the documented milestones found in the *Makerere University Comprehensive Historical and Spatial Tour V3*.
* **Offline Accessibility**: The platform must support offline data persistence to ensure that students can access historical records without requiring continuous mobile internet access.
* **Spatial Navigation**: The interface must provide an interactive map or navigation system that allows users to traverse the campus geography.
* **Chronological Filtering**: The system must include a timeline feature allowing users to filter historical landmarks by foundation year or category.

## User Stories
* **As a student**, I want to view the foundation year and historical profile of my hall of residence so that I can understand its origins and cultural identity.
* **As a researcher**, I want to filter landmarks by category (e.g., "College" or "Spiritual Sanctuary") to conduct targeted historical research.
* **As a visitor**, I want to navigate the campus map to locate iconic landmarks like the Ivory Tower or Freedom Square and read about their significance.
* **As a user with limited data**, I want the app to cache historical information locally so that I can browse the repository offline.
* **As an administrator**, I want to use a secured portal to update or modify landmark data to ensure the repository remains current.

## Technical Stack
* **Frontend**: Flutter (Mobile-first, cross-platform).
* **Backend**: Node.js/Express or Python/FastAPI.
* **Database**: SQLite (for local persistence) and PostgreSQL (for production).
* **Version Control**: Git.

## Development Roadmap
* **Week 1**: Structuring the database schema and initializing the project repository.
* **Week 2**: Implementing backend API logic and digitizing historical media assets.
* **Week 3**: Building the caching layer for offline persistence and timeline navigation.
* **Week 4**: Final visual polishing, bug-bashing, and deployment.
